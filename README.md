# LED_MQ2_PJ
# 공부 집중도 & 피로도 경고 타이머
# 팀원 :류원아

## 무엇을 만들었나
1.기본적으로 25분 집중 / 5분 휴식 타이머(포모도로) 역할을 LED 게이지 색상 변화로 보여줌
2. 타이머 중간에 MQ2 센서가 감지하는 공기 상태(예: 입김이나 밀폐 상태로 인한 공기 변화)가 나빠지면, 집중 모드 중이라도 즉시 경고등(주황색/빨간색)으로 전환되어 환기를 유도

## 어떤 부품으로
- 라즈베리파이 피코 2 W
- MQ2 가스 센서 / RGB LED 스틱

## 어떻게 연결했나
| 부품 | 피코 핀 |
|---|---|
| MQ2 | A0 (GP26) |
| LED | D16 (GP16) |
